GPT-6 Pro in ChatGPT can now split one task across several agents and work on it at the same time
It is an update OpenAI published in its October 16, 2026 release notes

It rolls out gradually starting with Pro plan users, and it is not available on Plus

![OpenAI wordmark](/assets/images/ai/gpt-6-pro-parallel-agents/01-openai-wordmark-mono.webp)
*OpenAI wordmark*

## What the update includes

![GPT-6 Pro update entry in the ChatGPT release notes](/assets/images/ai/gpt-6-pro-parallel-agents/02-release-notes.webp)
*GPT-6 Pro update entry in the ChatGPT release notes — Source: OpenAI*

[Faster responses]
Response speed improved, no figures disclosed

[Using plugins and tools]
Improved to make better use of plugins and tools when carrying out tasks

[Parallel agents]
Several agents work on different parts of one task at the same time

Progress can be seen inside the conversation
Opening a finished task lets you <mark>see what each agent did</mark>

The rollout goes <mark>gradually to eligible Pro users</mark>
For managed workspaces, it depends on admin settings and whether they are in the rollout

OpenAI's announcement on X called the same model **GPT-6 Astra Pro**
According to the help docs, GPT-6 Pro is based on GPT-6 Astra, so both names refer to the same model

## Plans that can use it

| Plan | Monthly price | GPT-6 Pro in Chat |
| :--- | :--- | :--- |
| Pro 100 | about $100 (₩140,000) | Included |
| Pro 200 | about $200 (₩280,000) | Included |
| Pro 500 | about $500 (₩700,000) | Not listed in docs |
| Plus | - | **Not included** |

It covers **Pro 100, Pro 200, Business, and Enterprise**
Plus cannot pick it in Chat and only uses GPT-6 Astra in Work and Codex

**Pro 500**, launched September 29, is not yet on the GPT-6 Pro list in the model docs
What sets Pro 500 apart from other plans is the Ultrafast speed mode

New sign-ups for Pro 200 were paused on September 11 and resumed on September 29

🔗 Link - https://blog.naver.com/rottensweetpotato/224408268614

New subscribers to the reopened Pro 200 get <u>less base usage than before</u>
People who were on Pro 200 between September 22 and 29 keep their previous usage <mark>until October 29</mark>

Pro is billed monthly only, with no annual billing
This update announcement does not mention any country restrictions

## Usage limits and how usage is deducted

![Base usage deduction multipliers compared with standard mode](/assets/images/ai/gpt-6-pro-parallel-agents/en/03-chart.webp)
*Base usage deduction multipliers compared with standard mode — Source: self-rendered based on OpenAI help docs*

GPT-6 Pro is not unlimited and has a **weekly usage limit**
On Pro 200, once the weekly limit runs out, it automatically switches to GPT-5.6 Thinking at the medium level

On Pro 100, GPT-6 Pro and GPT-5.6 Sol Pro <mark>share a single weekly allowance</mark>

The amount deducted also depends on the speed mode
Compared with standard, **fast mode deducts 2.5x** and Ultrafast deducts **8x**

Ultrafast is a speed mode for GPT-6 Astra and GPT-6.1 Sol in Work and Codex
OpenAI notes that these multipliers do not guarantee proportionally faster performance

How parallel agents deduct usage has not been disclosed
OpenAI's docs also give no figure for the maximum number of agents that can run at once

## How it differs from other agent features

![Concept shot of one task split into several branches](/assets/images/ai/gpt-6-pro-parallel-agents/04-agy.webp)
*Concept shot of one task split into several branches — Source: concept shot · self-generated with agy*

These parallel agents run while a single answer is being generated in the Chat tab

**dots**, launched September 29, is an always-on agent that keeps working between conversations
It uses the GPT-6 Astra model and has its own cloud computer

**Codex Cloud** keeps a separate isolated workspace for each coding task
The work continues in the cloud even if you close your laptop

Answers generated with Pro models <mark>do not support the Intelligent UI</mark> launched October 7
Answers with charts and buttons are supported only from Instant up to the Extra High level
