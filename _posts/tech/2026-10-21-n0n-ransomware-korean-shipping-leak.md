국내 해운, 항만, 철강 기업 12곳의 내부 자료가 다크웹에 공개됐어요!!
랜섬웨어 그룹 **N0n**이 협상 기한이 지나자 내려받을 수 있는 압축 파일을 공개했습니다

이번엔 고객 개인정보보다 **기업 업무 자료**가 중심이에요
12곳이 각각 침해됐는지, <mark>공급업체 한 곳</mark>에서 한 번에 유출됐는지는 아직 확인되지 않았어요

![컨테이너 터미널 위로 겹친 데이터 모듈 개념 컷](/assets/images/tech/n0n-ransomware-korean-shipping-leak/01-agy.webp)
*컨테이너 터미널 위로 겹친 데이터 모듈 개념 컷 — 출처: 개념 컷, agy 자가 생성*

## 사건 경과

![N0n 해운 항만 공격 경과 타임라인](/assets/images/tech/n0n-ransomware-korean-shipping-leak/02-chart.webp)
*N0n 해운 항만 공격 경과 타임라인 — 출처: SOCRadar, Cydome, 보안뉴스 기반 자가 렌더*

N0n은 **9월 18일** 처음 식별된 신생 데이터 탈취 협박 조직이에요
10월 12일 유출 전용 사이트에 해운, 물류 기업 <mark>38곳</mark>을 일괄 게시했습니다

그중 한국 기업이 12곳이었어요
보안뉴스가 10월 13일 명단과 기업별 요구액을 처음 보도했습니다

공개 기한은 10월 19일이었어요
보안뉴스는 10월 20일 기한이 지난 뒤 실제로 내려받을 수 있는 zip 파일이 공개됐다고 전했습니다

조직은 이번이 첫 공개분이라며 <u>합의 전까지 추가 공개</u>를 예고했어요

### 📋 국내 명단 12곳

| 분야 | 기업 |
| :--- | :--- |
| 항만 터미널 | **부산신항만**, 비엔씨티(BNCT) |
| 항만 터미널 | 동원글로벌터미널부산, 마산아이포트 |
| 해운 | 고려훼리, 폴라리스쉬핑, 동아탱커 |
| 해운 대리점 | 삼주마리타임, 새한마린 |
| 물류 | 유수로지스틱스, BKH ICD |
| 철강 | **동국제강** |

명단에 오른 것이 곧 침해 확인은 아니에요
10월 14일 기준 공개적으로 침해를 인정한 기업은 한 곳도 없었습니다

## 요구액과 기업 입장

![N0n 해운 물류 피해 주장 국가별 건수 막대 차트](/assets/images/tech/n0n-ransomware-korean-shipping-leak/03-chart.webp)
*N0n 해운 물류 피해 주장 국가별 건수 막대 차트 — 출처: SOCRadar 기반 자가 렌더*

38곳은 18개국에 걸쳐 있고 한국이 <mark>12곳</mark>으로 가장 많아요
브라질과 인도네시아가 4곳씩으로 뒤를 이었습니다

### 💰 기업별 요구액

보안뉴스가 전한 요구액은 **부산신항만**이 약 168억 원(1,200만 달러)이에요
유수로지스틱스는 약 196억 원(1,400만 달러)이었습니다

동국제강은 보도마다 숫자가 달라요
보안뉴스는 약 140억 원(1,000만 달러), Cydome는 <mark>약 1,400억 원(1억 달러)</mark>으로 적었습니다

게시물마다 **10% 선납 협상** 옵션이 붙어 있어요
Cydome는 140억 원이 그 선납액과 맞는다고 봤습니다

N0n은 기업마다 몸값을 다르게 정하고 비트코인으로 받으려 해요

### 🗣️ 기업과 기관 입장

동국제강은 "관련 사안은 인지하고 있으며 현재 대응 중"이라고 밝혔어요
같은 자리에서 "해킹 조직의 일방적인 주장일 뿐 실제 피해가 확인된 것은 아니다"라고 덧붙였습니다

**KISA**는 다수 항만 기업의 피해를 인지하고 해당 기업에 침해 사실을 안내 중이라고 했어요
한 피해 기업 IT 담당자는 KISA 안내를 받고 유출 내용을 파악하는 중이라고 전했습니다

## 단일 공급업체와의 연관 정황

![38곳 중 한 공급업체로 이어지는 단서 막대 차트](/assets/images/tech/n0n-ransomware-korean-shipping-leak/04-chart.webp)
*38곳 중 한 공급업체로 이어지는 단서 막대 차트 — 출처: Cydome 기반 자가 렌더*

해운 보안 업체 **Cydome**는 10월 15일 분석을 냈어요
이 자료가 서울의 해운 소프트웨어 기업 **CyberLogitec**과 연결된 것으로 보인다는 평가입니다

38곳 중 <mark>21곳</mark>이 공개 자료로 확인되는 CyberLogitec 고객사였습니다

샘플 파일 7개에는 이 회사나 제품 이름이 직접 나왔어요
부산신항만 샘플은 테스트 환경 배포 목록, BKH ICD 샘플은 터미널 운영 시스템 릴리스 노트였습니다

Cydome는 자료 보관함 하나의 파일이 고객사별로 나뉘어 게시됐을 가능성을 제시했어요
한 게시물이 다른 게시물의 샘플 파일을 그대로 다시 쓴 사례도 짚었습니다

### 🔍 아직 확인되지 않은 것

CyberLogitec은 국내 매체에 명단 속 국내 기업이 자사 고객이 맞다고 확인했어요
고객사에 예방 안내를 보냈고 **시스템은 정상 운영 중**이라고 밝혔습니다

Cydome가 확인한 범위에서 CyberLogitec은 침해 사고를 인정하지 않았어요
어느 시스템에 어떻게 접근했는지, N0n이 직접 빼냈는지 제3자에게서 샀는지도 <u>확인되지 않았습니다</u>

SOCRadar는 N0n이 이전 피해자에게는 **인포스틸러**로 수집한 계정으로 들어갔다고 정리했어요
인포스틸러는 PC에 설치돼 저장된 비밀번호를 탈취하는 악성코드입니다

## 유출 주장 자료와 피해 범위

| 자료 종류 | 상태 |
| :--- | :--- |
| 내부 엑셀, 계약서, 인보이스 | <mark>공개됨</mark> (보안뉴스) |
| 선박 일정, 수출 실적 | 공개됨 (보안뉴스) |
| 시스템 릴리스 노트, 패치 스크립트 | 샘플 확인 (Cydome) |
| EDI 컨테이너 전문 | 샘플 확인 (Cydome) |
| 사용자 계정 목록과 비밀번호 | **주장**, 일부 샘플 |
| 개인 고객 정보 | 확인 안 됨 |

**EDI**는 선사와 터미널이 화물 정보를 주고받는 전자 문서예요
Cydome는 EDI 전문에 <mark>다른 선사의 화물 정보</mark>도 포함돼 있을 수 있다고 봤습니다

그래서 명단에 없는 화주와 거래처도 영향을 받을 수 있어요
계정 목록이 실제 유출 자료라면 <u>연동 시스템 무단 접근</u>도 위험해집니다

SOCRadar가 확인한 부산신항만 자료 표본은 1.5GB에 파일 774개였어요
샘플 파일 날짜는 2009년부터 2026년 8월까지, 계정 예시는 2018년부터 2022년까지였습니다

## 신고 의무와 해야 할 일

정보통신서비스 제공자는 침해를 알게 된 때부터 24시간 안에 신고해야 해요
2024년 8월 14일 시행된 <mark>정보통신망법</mark> 개정 조항입니다

개인정보가 섞였으면 개인정보보호법상 72시간 안에 유출 신고도 따로 해요
KISA는 해킹에 따른 개인정보 유출이면 <u>침해사고 신고와 유출 신고를 각각 접수</u>하라고 안내합니다

SOCRadar는 공유 플랫폼부터 점검하라고 권고했어요
EDI 허브, 터미널 시스템 공급업체, 파일 전송 서비스가 내 자료를 보관하는 곳입니다
